## Variant: Quiet Card (classic, app-style)

### Design stance
The conventional modern auth screen — centered logo, one elevated card, one primary button. Calm and instantly legible; the "newspaper" lives only in the serif and rules.

### Key choices
- Layout: centered stage, logo row above a 400px elevated card (surface bg + shadow-lg, radius 4)
- Typography: serif headings, mono kickers; zero newspaper theatrics
- Color: exact Broadsheet tokens, dark/light toggle
- Interaction: Google spinner → "sketch only" note (single entrance; no guest path)

### Trade-offs
- Strong at: instant familiarity, zero learning curve, mobile-perfect by default
- Weak at: could be any app; no editorial personality — the ink-and-paper identity is only in the fonts
