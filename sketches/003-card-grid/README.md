## Variant: Card Grid

### Design stance
Modular dashboard. Each concern (continue studying, flashcards, AI, daily goal, weekly heatmap, courses, activity) is an independent card in a responsive grid. Scan-friendly, no forced hierarchy.

### Key choices
- Layout: 3-column responsive card grid, featured card spans 2 cols
- Typography: Friendly greeting with streak motivation, bold numbers in cards
- Color: Teal progress ring for daily goal, heatmap squares for weekly activity, amber for flashcards
- Interaction: Each card is a tappable unit, activity timeline in bottom-right

### Trade-offs
- Strong at: Visual variety, scannable, mobile-friendly (cards reflow to single column), modular (easy to add/remove cards)
- Weak at: No single primary action — all cards compete for attention, more visual noise

### Best for
Users who like seeing everything at once in a tile layout. The "Continue studying" featured card and daily goal ring together give both urgency and progress feedback.
