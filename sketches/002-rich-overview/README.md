## Variant: Rich Overview

### Design stance
Information-rich command center. Sidebar navigation + dense stat panels + course progress + chart — everything visible without scrolling much.

### Key choices
- Layout: Icon sidebar + two-column content area
- Typography: Compact headers, uppercase labels, small stat cards
- Color: Color-coded course progress bars (blue, emerald, purple), teal accents
- Interaction: Sidebar nav, search bar, hoverable course/document rows, upload button prominent

### Trade-offs
- Strong at: Power users who want a bird's-eye view of everything at once
- Weak at: Higher cognitive load, sidebar eats horizontal space on mobile, more cluttered

### Best for
Users with multiple courses who want to see progress across everything. The 5 stat cards at the top (today/week/streak/docs/flashcards) are the reference panel.
