## Variant: Big Ledger (editorial split-screen)

### Design stance
A two-page ledger spread: the left "page" argues why you should sign, the right page is where you sign. Editorial ambition kept functional.

### Key choices
- Layout: split-screen grid (1.15fr / 1fr). Left: brand, kicker "The Registry", oversized headline "Every scholar signs the ledger.", justified deck, №1–3 value entries under a double rule. Right: "Sign the ledger" — a single bordered Google row with arrow
- Typography: big serif display (up to 54px), mono kickers and fine print
- Color: exact Broadsheet tokens, dark/light toggle
- Interaction: Google row spinner → sketch note; fine print states the privacy story ("NO PASSWORDS ARE KEPT IN THIS HOUSE"); single entrance, no guest path

### Trade-offs
- Strong at: sells the product while signing in; most "designed" of the three; strong desktop presence
- Weak at: heaviest; left column collapses on mobile (entries hidden), so mobile loses the persuasive half
